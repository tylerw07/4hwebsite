4-H Club Money Tracker

A Simple Budget Tracker for 4-H Clubs — Computers Project

Project Overview

I created a 4-H Club Money Tracker using HTML, CSS, and JavaScript. This tool is designed to help 4-H clubs and their treasurer track income and expenses in a simple, easy-to-use web page that anyone can open in a browser.

Features

  • Track Income & Expenses — Log money coming in and going out with a few simple clicks
  • Live Balance — The balance updates automatically every time you add a transaction
  • Income & Expense Types — Switch between Income and Expense via a dropdown
  • Savings Tip — A tip encourages staying above the 20% savings goal
  • Color Coded — Income is shown in green, expenses in red

AI Assistance

In addition to this project, I took on the task of making my code more appealing and easier to understand. To achieve this, I enlisted the help of Claude AI to upgrade my existing code, specifically focusing on enhancing its user-friendliness.
